# Redroid Device Center — 功能规格（闭环对照）

本文是实现与验收清单。每条有 ID。状态：`[ ]` 未完成 / `[x]` 已落地。

**明确不做：** Magisk / LSPosed / 隐藏模拟器 / 改指纹 / 绕过购物 App 风控。

**闭环定义：** 入口 → 操作 → 状态反馈（状态栏 / 进度 / 结果）→ 可回看或跳转相关页。

对照日期：2026-08-25。对照以代码行为为准。
