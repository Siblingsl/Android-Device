# 开源发布准备计划

日期：2026-09-21

## 目标

把仓库整理到可以由维护者完成最终法律、凭据和发布确认的开源候选状态。

## 范围

- 移除已跟踪的环境配置，提供脱敏示例配置。
- 补充开源发布检查清单和第三方资产归属边界。
- 修复依赖安全更新；Vitest 采用兼容 Node 20/Vite 7 的 v4.1.11，不升级到要求 Node 22 的 v5。
- 保留用户必须决定的许可证、凭据轮换、Git 历史重写、二进制再分发和签名事项。

## 不做

- 不替维护者选择软件许可证。
- 不删除或重写 Git 历史。
- 不删除第三方二进制资产，直到维护者确认许可证和再分发权。
- 不宣称真实设备、WHPX 或生产发布已验收。

## 验证

1. `npm audit` 与锁文件检查。
2. `npx tsc --noEmit`、`npx vitest run`、`npm run build`。
3. `git diff --check` 与敏感文件路径复查。
