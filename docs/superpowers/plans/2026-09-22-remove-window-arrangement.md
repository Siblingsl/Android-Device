## 目标

移除设备中心的“窗口编排”用户功能，避免页面继续展示入口或在启动时自动恢复独立设备窗口。

## 范围

1. 删除设备中心顶部“窗口编排”入口、弹窗挂载和相关状态。
2. 删除应用启动时按保存布局自动打开独立窗口的逻辑。
3. 清理仅服务于该功能的前端组件、布局存储和样式；保留普通设备页、批量投屏布局以及底层未被本次范围要求删除的通用能力。
4. 更新回归测试，确认入口不再出现。

## 验证

- 先运行设备页回归测试，确认新增断言在修改前失败。
- 修改后运行定向设备页测试、`npx tsc --noEmit` 和全量 `npx vitest run`。
- 按项目门禁运行两套 Rust 测试；本轮不修改 Rust 代码，仅确认现有工作区改动不受影响。
