# Dashboard 网格对齐方案

## 目标

让 Dashboard 顶部六张统计卡片与下方“设备状态 / 系统通知”两张卡片共享同一组纵向分栏线，修正截图红框处的错位。

## 根因

- 统计区是 3 等分列，列间距为 7px。
- 下方双栏区使用 `1.35fr / 0.65fr`，且间距为 8px。
- 两组网格的分栏计算方式不同，导致双栏区的左边界既没有落在第三张统计卡片的左边，也没有让第一张双栏卡片的右边对齐第二张统计卡片的右边。

## 方案

保留现有 DOM 和响应式断点，仅调整 Dashboard 桌面布局：

1. 抽出 Dashboard 网格共用的 7px 列间距。
2. 统计区继续使用三等分列。
3. 双栏区第一列宽度按“两个统计列 + 一个列间距”计算，第二列填充剩余空间。
4. 900px 以下仍由既有媒体查询切换为单列，不改变窄屏布局。

## 验收

- Dashboard 桌面宽度下，双栏区的分栏线与统计区第三列左边界重合。
- 双栏区第一张卡片右边界与统计区第二列右边界重合。
- 现有 TypeScript、Vitest 与两套 Rust 测试保持通过。
