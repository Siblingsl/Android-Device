# 设备应用导出 APK

## 问题

设备详情页的应用列表已经展示了每个应用的 APK 路径，但行操作的“更多”菜单只有复制包名、清数据和卸载，无法把已安装应用的 APK 导出到本机。

## 目标

- 在应用行的“更多”菜单增加“导出 APK”。
- 使用应用记录中的 `apkPath` 作为设备端源文件。
- 通过现有保存对话框让用户选择本机 `.apk` 文件路径，再复用现有文件下载命令完成导出。
- 导出过程中显示状态，成功后显示保存路径；取消保存时保持静默，失败时给出错误提示。
- 导出文件名默认使用包名，避免应用显示名称包含不适合作为文件名的字符。
- 导出必须使用文件管理页已验证的可跟踪下载流程，直接写入用户选择的目标文件，不能把目标路径交给会创建临时目录的普通下载封装。
- 中英文文案完整，不修改后端接口。

## 非目标

- 不重新打包、签名或修改 APK。
- 不修改设备端 APK 路径解析和应用列表接口。
- 不改变现有安装、启动、停止、清数据和卸载操作。

## 验收

- 应用行“更多”菜单出现“导出 APK”。
- 选择保存位置后调用现有 `downloadFileTracked(serial, apkPath, localPath, operationId)`，最终文件必须落在 `localPath`。
- 默认保存名为 `<安全包名>.apk`，并限制保存类型为 APK。
- 成功、失败、取消三种结果分别有正确的状态行为。
- TypeScript、Vitest、构建和 Rust 测试通过。
