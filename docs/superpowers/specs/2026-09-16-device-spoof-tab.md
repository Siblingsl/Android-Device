# 设备详情伪装专用 Tab

## 问题

设备详情页的“设置”同时承载普通设备设置、设备伪装和对抗自检审计，导致设置页内容过长，也不容易区分普通运行参数与伪装相关操作。

## 目标

- 在设备详情页新增独立的“伪装”Tab。
- 将“设备伪装”和“对抗自检审计”完整放入该 Tab，集中承载伪装档案、深度伪装、地理一致性、电池伪装和审计操作。
- “设置”Tab 只保留显示、网络、投屏参数、容器入口和自动启动等普通设置。
- 保留原有组件状态、调用逻辑及 session draft 存储键，避免迁移后丢失配置。
- 中英文 Tab 名称和工作区说明保持完整。

## 非目标

- 不修改伪装或审计的后端命令、业务逻辑和接口。
- 不改变伪装档案或电池伪装的存储格式。
- 不调整其他设备详情 Tab 的布局。

## 验收

- 设备详情导航出现独立“伪装”Tab，并可被 sessionStorage 恢复。
- 伪装 Tab 显示设备伪装与对抗自检审计两张卡，且两张卡均占满工作区宽度、按纵向顺序排列。
- 设置 Tab 不再渲染这两张卡。
- 中英文动态 i18n key 完整，TypeScript、Vitest、构建检查通过。
- 实际页面切换与卡片视觉效果待人工刷新确认。
