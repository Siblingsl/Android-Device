# Redroid Device Center Beta 主演示脚本

目标时长：3–5 分钟。主视频只展示一条已经通过 QA 的轨道；另一条轨道和 Root/GApps 高级能力作为补充片段。

## 录制前

- 使用实际 Tauri 应用和已发布版本，不使用浏览器预览。
- 关闭无关窗口和敏感信息，确认应用版本可见。
- 准备一台可以快速完成首台设备路径的环境。
- 确认截图、日志和设备名称不包含个人或内部信息。

## 时间线

| 时间 | 画面 | 旁白/重点 |
|---|---|---|
| 0:00–0:20 | 应用首页和容器与节点入口 | 这是面向 Android 自动化开发、云手机控制和 App 测试的 Windows x64 Beta。 |
| 0:20–0:50 | 环境准备清单 | 先看依赖状态；缺什么、为什么缺、如何处理都在页面和文档中说明。 |
| 0:50–1:40 | 选择 Docker 或 QEMU，创建无 GApps 基础设备 | 先验证首台设备成功，再增加高级预装，降低第一次使用的变量。 |
| 1:40–2:20 | 设备列表、ADB 状态、设备详情和一次基本控制 | 展示设备在线、serial、截图或基本控制。 |
| 2:20–2:50 | 来源徽标和只读对比视图 | Docker 与 QEMU 保持独立；无数据时显示不可用，不伪造数值。 |
| 2:50–3:30 | 一个真实错误或限制提示 | 例如 Android 14 使用 Android 13 GApps 会在创建前被明确拒绝。 |
| 3:30–4:30 | 可选能力或升级恢复补充 | 只展示已经有证据的能力，并说清版本和授权测试边界。 |
| 4:30–5:00 | README、兼容性矩阵和排障文档 | 引导观众按文档安装，遇到问题附环境和日志提交 Issue。 |
